# AllSwap

Open source published by [AllSwap](https://allswap.io), a non-custodial cross-chain swap service.

| Repository | What it is |
| :--- | :--- |
| [multichain-memo-address-validator](https://github.com/allswapio/multichain-memo-address-validator) | Zero-dependency mainnet address and checksum validator for 12 address families. |
| [mcp-server](https://github.com/allswapio/mcp-server) | Read-only Model Context Protocol server: public asset catalog, official channels, block-explorer links. |
